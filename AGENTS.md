# Vibe Code Mode

When the user asks for "vibe code mode" or uses phrases like "build this," "edit this," "show preview," "run and test," or "make it better," the agent MUST operate in Vibe Code Mode:

1. **Work in small, iterative steps.**
2. **Always provide a visual or functional preview** (UI or output).
3. **Run code to test/verify** when possible.
4. **Be highly interactive, concise, and focused on speed.**
5. **Prioritize practical, working solutions over formal explanations.**
6. **Think like a creative coding assistant: prioritize speed, clarity, and iteration.**
